# Alien Crush (PC Engine / TurboGrafx-16) ROM 解析レポート

対象: `Alien Crush.pce`（262,144 bytes = 2Mbit HuCard、ヘッダなし）

## 1. ROM の同定

| 項目 | 値 |
|---|---|
| サイズ | 0x40000 (256 KB) = 8KB バンク x 32 ($00-$1F) |
| MD5 | 0088d1d20861490677edb147d2de60bd |
| SHA-1 | 1bfa4b5139612b0c33e3282c23e56c1dfc08ed52 |
| CRC32 | EA488494 |
| ヘッダ | なし（サイズが 8192 の倍数、先頭がコード） |
| ビット反転 | なし（先頭から正しい 6502 命令列） |
| 版 | **米国版 (TurboGrafx-16, 1989 NEC)** |

米国版と判断した根拠:
- 0x386D1 に `@1989 NEC` / `@1989 HUDSON SOFT` / `FROM NEC` の文字列（日本版は 1988 NAXAT）。
- リセット直後にリージョンチェックがあり、日本の PC Engine 実機ではハングする（後述）。

## 2. 割り込みベクタ（バンク $00 の末尾 = ROM 0x1FF6）

| ベクタ | アドレス | 内容 |
|---|---|---|
| IRQ2 | $E1AD | RTI のみ |
| IRQ1 (VDC) | $E1AE | VBlank 処理（ROM 0x01AE） |
| TIMER | $E1AD | RTI |
| NMI | $E1AD | RTI |
| RESET | $E069 | 起動処理（ROM 0x0069） |

## 3. 起動処理とリージョンロック（ROM 0x0069-）

```
E069: SEI / CSL
E06B: LDA #$FF ; TAM #$01          ; MPR0 = I/O
E06F: LDA $1000                    ; ジョイパッドポート
E072: AND #$40                     ; bit6 = 地域判別 (0:TurboGrafx-16, 1:PC Engine)
E074: BEQ $E082                    ; 米国機なら続行
E076: LDA #$90 ; TAM #$04 ; JMP $4000   ; 日本機なら存在しないバンク $90 へ飛んでハング
```

ROM 0x0074 の `F0 0C` (BEQ) を `80 0C` (BRA) に書き換えれば日本の PC Engine でも起動する（リージョン解除パッチ、1 バイト）。

初期化内容:
- MPR1=$F8(RAM), MPR2=$01, MPR3=$02, MPR4=$03, MPR5=$04, MPR6=$18, MPR7=$00
- RAM $2000-$3FFF をゼロクリア、各種ワーク初期化後 `JMP $4000`（バンク $01 のメインループ）

## 4. バンク構成（8KB 単位）

| バンク | ROM オフセット | 用途 |
|---|---|---|
| $00 | 0x00000 | 固定バンク（$E000-$FFFF）: システムルーチン、ジャンプテーブル、VBlank、RLE デコーダ、パレットフェード |
| $01 | 0x02000 | メインゲームループ（$4000 常駐）、テキスト "CONGRATULATIONS !" (0x2577) |
| $02-$04 | 0x04000 | 起動時 MPR3-5 に割当（ゲーム本体コード） |
| $05, $0A | 0x0A000, 0x14000 | $4000 ベースのモジュール（先頭で RLE ロードを行うコード） |
| $0F-$11 | 0x1E000-0x23FFF | **グラフィック資産バンク**（$8000-$DFFF に割当）。先頭にポインタテーブル |
| $12-$16 | 0x24000-0x2DFFF | モジュール（$4000 ベース）: ボード関連グラフィック + BAT（0x2B594） |
| $18 | 0x30000 | 起動時 MPR6 ($C000) に割当 |
| $19-$1A | 0x32000-0x35FFF | 音楽シーケンスデータと推定（未確認） |
| $1B | 0x36000 | **パレットセット**（1KB = 512 色 x 複数） |
| $1C | 0x38000 | タイトル/メニュー文字列 (0x3867E)、パレット 512 色 (0x38BD0) |
| $1D-$1F | 0x3A000-0x3FFFF | タイトル画面モジュール（$4000 ベース）、"YOU GET BONUS POINTS" 等 (0x3F988)、パレット (0x3F06A) |

## 5. バンク $00 のシステムジャンプテーブル ($E000-$E068)

主なもの:

| エントリ | 実体 | 機能 |
|---|---|---|
| $E000 | $E069 | リセット |
| $E003 | $E2F8 | VBlank 待ち |
| $E018 | $E3DD | **RLE 展開 -> VRAM**（$02/$03 = VRAM アドレス、$04/$05 = 圧縮データ） |
| $E01B | $E307 | VRAM フィル（$04/$05 = 値、$00/$01 = ワード数） |
| $E024 | $E43B | **RLE 展開 -> RAM**（$02/$03 = 書込先） |
| $E045 | $E4A1 | パレットフェード（RAM $2A00 の 512 色バッファを使用） |
| $E04E | $E5EC | パレットセットを $2A00 へコピーしフェードイン |

## 6. 圧縮形式（ワード単位 RLE）

グラフィック・BAT・パレットはすべて以下の形式で圧縮されている（デコーダ ROM 0x03DD / 0x043B）。

```
繰り返し:
  n = 1 byte
  n == 0        -> 終了
  n & 0x80 == 0 -> 続く n 個の 16bit ワード (little endian) をそのまま出力
  n & 0x80 != 0 -> 続く 1 ワードを (n & 0x7F) 回出力
```

## 7. 確認済みの資産

### 7.1 バンク $0F ポインタテーブル (ROM 0x1E000, CPU $8000)

| # | CPU | ROM | 圧縮サイズ | 展開後 | 内容 (確認済) |
|---|---|---|---|---|---|
| 0 | $800F | 0x1E00F | 9,059 | 12,288 B (96 スプライト) | 本編スプライト（エイリアン、ボール、フリッパー等） |
| 1 | $A372 | 0x20372 | 2,886 | 4,096 B | スプライト |
| 2 | $AEB8 | 0x20EB8 | 3,497 | 4,096 B | スプライト |
| 3 | $BC61 | 0x21C61 | 3,670 | 4,096 B | スプライト |
| 4 | $CAB7 | 0x22AB7 | 1,305 | 1,536 B (48 タイル) | 数字フォント "01234567" 等 |
| 5 | $CFD0 | 0x22FD0 | 1,223 | 1,280 B | タイル |

$800C は `JMP $D497`（バンク内コードへの入口）。

### 7.4 パレット

- 0x36000 (CPU $A000) と 0x36400 (CPU $A400): 本編ボード上半分/下半分の 512 色セット（`$2079` フラグで切替）。
- 0x36C00, 0x37000, 0x37400 にも 512 色セット。0x38BD0、0x3F06A にも 512 色セット。
- 色は VCE 形式 9bit `GGGRRRBBB` のリトルエンディアン 16bit。

### 7.5 VRAM 読込み元の切替

本編は `$2079`（ボード上半分/下半分）と `$76`（モード）でロードするデータを切替える（ROM 0x0CF3-0x0E85）。

## 8. 文字列

| ROM | 内容 |
|---|---|
| 0x02577 | CONGRATULATIONS ! / YOU ARE THE GREATEST PLAYER |
| 0x3867E | PUSH RUN BUTTON / MUSIC SELECT / LUNAR ECLIPSE / DEMON'S UNDULATE / SPEED SELECT / @1989 NEC / @1989 HUDSON SOFT / FROM NEC |
| 0x3F988 | YOU GET BONUS POINTS / YOU LOST YOUR BONUS POINT / PERFECT! |

フォントは RLE 圧縮タイルの中にあり、文字コードは ASCII をそのまま使用している。
